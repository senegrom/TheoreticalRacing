      Think ahead. Brake early.

      This is the original vector racing game, not a real-time driving simulation. On every turn, choose an acceleration: −1, 0 or +1 on each axis. Your car moves by its new velocity.

      Your turn

      Select a direction in the 3 × 3 pad, or tap a destination on the track. The dashed line previews the original engine’s braking path. Press Confirm move or Enter to drive. Red × destinations crash; taking one requires confirmation.

      Use Q W E / A S D / Z X C, or the numeric keypad, for the nine directions. Arrow keys select N, S, E or W. Space selects no acceleration, not a brake. U undoes your last decision and all AI replies. Keyboard shortcuts work after clicking a control too; typing inside an input never drives the car.

      Tracks and placement

      Place your car on a highlighted start point. Drag the board to pan; pinch or scroll to zoom. Fit shows the full track, and Car / start zooms to the current driver. Coordinate inputs offer an alternative to clicking small grid points.

      For a custom course, draw the left border from start to finish, continue, then draw the right border in the same direction. The original geometry validator rejects intersecting borders.

      Winning and collisions

      Finish crossings must be in the forward racing direction. Multi-lap circuits retain their original checkpoints and lap gates. Leaving the corridor or landing on another active car crashes you. The original Java game ends when its finish condition is met, including assigning the last remaining driver a place. A final rank does not necessarily mean that driver crossed the line.

      Large tracks calculate the same full reachability maps as the desktop game and can require substantial time and memory. AI pacing only changes the delay between turns, never the policy. Keep this tab open; races are not restored after a reload.
      Keep it on your home screen

      Install Theoretical Racing

      iPhone or iPad: open this page in Safari, choose Share, then Add to Home Screen. Leave Open as Web App enabled when offered, then tap Add.

      Mac: in Safari, choose File → Add to Dock. In Chrome or Edge, use the browser’s install-app command when offered.

      Android: use Install app or Add to Home screen in your browser’s menu.

      The racing icon is supplied for both browser tabs and installed apps. An older saved shortcut may need to be removed and added again to pick up the new icon.

      Installation is a shortcut to this web app, not an offline download. Internet access is needed to load the Java runtime. An active race is not saved when you reload or leave this page.
